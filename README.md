# UART-Between-STN32NF103RB-and-Aurdino-UNO
UART communication was established between the STM32F103RB and Arduino Uno using the STM32 HAL Library. Both devices were configured at 115200 baud. Data was successfully transmitted from the STM32 and received by the Arduino, while responses from the Arduino were correctly received by the STM32, demonstrating reliable two-way serial communication.
